#Roles
HTML: Estructura del sitio web. Ejemplo concreto: Crear una sección donde se muestren las bicicletas disponibles para alquilar.
CSS: Diseño y apariencia visual. Diseñar la página de Rueda Libre con colores relacionados con la naturaleza y la movilidad sostenible
JavaScript: Interactividad y funcionalidad. Ejemplo concreto: Cuando un usuario seleccione una bicicleta y elija la cantidad de horas que desea alquilarla, JavaScript calculará automáticamente el precio total del alquiler y lo mostrará en pantalla.

#Formulario
1. Para el campo de correo electrónico se utilizó el tipo email, ya que este ayuda a confirmar los requisitos necesarios para que en realidad se esté ubicando allí un correo electrónico
2. Para el campo de documento, se utilizó un campo tipo text, no se usó tipo number, ya que este tipo, no nos permite digitar el número 0 al principio. Además se le limitó a 10 digitos, pero además se les agrega un inputmode=numeric, para que confirme que solo se digiten números en este campo
3. Para la casilla de aceptación de políticas de alquiler, se usa el tipo checkbox, lo que permite seleccionar esta opción la cual es requerida para enviar el formulario.
